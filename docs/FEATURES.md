# Rainbow Six Siege Settings Panel — feature reference

Rainbow Six Siege Settings Panel focuses on three connected areas: control groups, display settings, keybind reference. Its organization keeps frequently used options close to the context they belong to.

| Section | Description |
|---|---|
| Control groups | A dedicated section for control groups and the configuration details associated with that area. |
| Display settings | Display or performance-related options, with space for configuration and comparison information. |
| Keybind reference | Shortcut assignments and control mappings, organized in one reference section. |

The project page follows the same section structure.
